# 知识库、资料索引与原文迁移

本节是建模与实施流程；不是任何套餐的权益承诺。原文目录上传及下载摘要一致有一次实测，真实成员权限、全量主库切换与自动维护另行验收。

## 1. 稳定入口与权限
- 用固定首页链接填报、统计、标准、工作依据和帮助；每个链接说明用途与对象，只将已可用的资源列为正式入口。管理员底册、核对记录和工具另页管理，核对该页是否继承公共权限。
- 多维表格空间用于组织数据库与应用，知识库用于导航和原文。两者均有自己的成员/继承权限；不要因首页可访问就推断所有链接也可访问，或将成员加入空间默认角色以“解决”应用访问。
- 先单单位样例，实际账号检查底表直链、搜索、关联选项、查找汇总及导出。未验证入口标试用，不扩为正式全员入口。

## 2. 资料与版本
- 标准版本、产品适用对照、工作依据按各自粒度拆表；国家标准/行业标准与全国/省级工作依据分目录。保留一个原文，多处引用其链接，避免每个产品再上传同一文件。
- 每个版本记录稳定编号、原文名称、文件大小、摘要、文件标识、原文链接、来源、核验日期、状态、替代关系和缺件原因。缺原文、候选、适用性待核要明确，不补造内容。
- 历史登记状态保留核验时点。实施日期已到不代表官方状态已核查，不能只因当前日期变化批量改状态。案卷保存实际采用版本与原文链接，不随最新版本替换，也不只凭检查日期推断适用版本。
- 同 Base 关系用原生关联；跨 Base 一期可用明确版本编号和原文链接，跨库同步能力与权益按当前账号核查，不预设免费可用或完全不支持。

## 3. 分批上传与回读
1. 先确认目标企业、当前认证状态、剩余容量和单文件上限；官方条款与当前账号界面都回读。不为上传启用试用或购买。受限文件保留本地及登记。
2. 样本覆盖历史版本、缺原文、大文件和扫描件。原件不动，临时副本保留原字节及摘要；上传时选择原文件，除非用户明确需要转换为在线文档。
3. 上传成功提示只是过程结果；刷新目录、打开目标文件、登记实际链接，再下载恢复样本比对大小与摘要。失败/超限/缺件分别记状态，未知结果先查已存在对象，不重复上传。
4. 导入索引后全量核主键、字段类型和文字；说明列可能被推断为多选并改写中文标点，不能靠行数正确就验收。修复仅针对差异单元格，保留失败导出。

## 4. 飞书成为主库的门槛
- 入口、登记、原文、版本引用和一次完整更新闭环均通过后，再切换维护流程。逐层区分“已创建、已上传、已校验、已授权、已切换”。
- 如有周维护，沿原入口、时间和绑定实施读取云端登记、官方核查、临时下载校验、云端更新及回读；未经本阶段验收不先关闭本地维护。
- 切换前保留原件；切换后的本地缓存/导出不应成为另一套手工主库。历史原件清理列精确批次另验，不因上传成功顺带删除。
