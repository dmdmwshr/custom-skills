# macro-strategy 数据运行

先确认实际主机、用户、项目根和阶段，读取项目 AGENTS.md、唯一 PROJECT_PLAN.md、PROJECT_HANDOFF.md；运行与发布定位从项目运行说明、配置和 systemd 回读。本流程已在 WSL 验证，其他 Linux 主机须先核实依赖和部署入口；不推定 Windows 可执行。

## 接入与范围

当前项目与旧 OKXnew 独立。旧项目的代码、运行库、检查点、服务、交易认证和 Cookie 不能成为恢复入口；先前退役回执只是外部交付证据。只读请求保持只读，已明确授权实施时由当前任务直接完成，不因固定任务名称重复转交。

来源和标的以当前项目配置及登记表为准；模板和 synthetic 默认不触网。开发验证使用项目受限 systemd worker，网络采集保持一个业务写者；回执在新建仓外目录，不复用旧任务的 worker 或回执。模拟传输测试与正式数据库分开，不把 probe 数据导入正式库。

## 故障与接续

- 先回读当前发布、单元状态、唯一 PID、锁、各源 state/next_due、分页及追赶状态。旧 PID 不是持久身份；正常重启沿原运行根与检查点接续，不能另开采集进程补历史。
- 传输失败应只记录固定类别（连接/读取超时、代理、协议等），不输出异常正文、URL、request或凭据；默认退避与已持久next_due保持。旧记录只有transport_failure时不能反推具体根因。
- history 游标与停机追赶是两件事。追赶未完成又出现新缺口时必须登记额外区间；测试应覆盖两次长中断和中途进程重建。空页只证明接口边界，不能证明上市以来无遗漏；按实际小时差距报告缺口。
- 页面数据与游标同事务提交；失败后只续最后成功检查点。GET 请求失败按分类及持久 next_due 接续，429及503尊重响应收到后的 Retry-After；整个来源限流或503时停止该轮其余请求，并验证next_due跨重启保留。结果未知先查 worker 和回执，不重跑安装或业务动作。
- 近一年历史并非只下载一次。SPDR 初扫完成后仍按计划回扫窗口以捕捉修订；交叠去重、A→B→A 和取得时间单调均需验证。发布日历未知时，不把自然日空档直接称漏采。
- 金十 MCP 在新进程通过 systemd credentials 注入；只核对协议、tool schema 和允许调用。工具清单未暴露某历史能力，只能描述本次账号/端点范围。日历只投影目标事件时间，不落实际/预测/前值；当周匹配0事件不等于认证失败或全年无风险事件。
- 持续服务须覆盖正常退出、崩溃和依赖恢复。采用systemd notify/watchdog时，READY在数据库迁移完成后发送，由真实主线程进度喂狗；长响应分块可更新独立原子活性文件，不能为了喂狗提前提交业务事务。验收区分进程退出自动恢复、显式stop保持停止和WSL启动后enable；后者不证明Windows开机必定启动WSL。

## 网页来源核验

浏览器验证使用当前主机登记的受管 Playwright 入口：各项目独立官方会话与原生页面组，共用统一控制租约。具体配置、临时目录、下载位置和部署约束按主机 host-baseline 的浏览器说明回读，不在业务技能复制绑定值；不另建并行控制者。

已迁移ProjectBrowserV2的WSL项目只引用主机唯一契约；用一次持久入口完成attach、page-ensure、业务操作、page-release和显式finish，之后退出入口再等collector。页面默认临时，WGC下一轮无同页复用需求，不强留连接页或旧CLI生命周期。先正常退役旧CLI并确认无在途/daemon退出，再锁内精确切本项目backend，保持原collector；真实组名、groupId与页面原生身份须有回执。

新页首份tabId可能尚为空，按契约inventory补读，不能猜。顶层成功或cleanupPending=false不等于关闭：核对release.closed、目标页消失、finish各清理类别、精确finish请求对应的状态及owner/pending释放。所有业务页已确认关闭后，主机finish可能出现已验证的空连接换代；保留业务阶段和终态两份原生身份，不把正常终态变化误判成下载失败或重放click。业务阶段身份改变仍停止对账，EOF仅best-effort不当验收。

WGC 官方下载在扩展模式下可能没有可靠的download或response完成事件，但文件已进入浏览器默认下载目录。点击后按已知文件名、操作时间、稳定大小和目标目录核对完整文件及哈希，不把等待事件作为唯一完成依据。原始调用回执先保存；未知pending先对账，即使文件已完成也不能伪造成功回执或直接重点击。必要连接退役、恢复及页面清理由主机统一控制层执行，业务项目只声明用途和留存。全球季度 Central Bank and Other Institutions 与月度已报告储备变动口径不同，不能互相替代；当前修订版本也不是历史vintage。

已使用的 FRED 公开 CSV 下载不要求 API Key；ALFRED 网页下载与 FRED/ALFRED API 认证是不同入口，分别验证。不能从网页可读推定 API 已授权、全部 vintage 齐全或历史从未配置过 Key；网页下载、实际取得文件与点时覆盖分别报告。

已连接应用要在实际任务重新发现工具并做最小调用。TradingCursor的request_analysis返回AI分析，不是TradingView官方MCP或原始OHLCV历史；完成时间不作行情时间，叙述与字段不一致时不作为来源事实。遇提供方冷却/额度拒绝按原响应保留未验证，不重复登录、升级订阅或绕限额；工具参数未提供历史区间/原始bar时不把分析端点接入定时行情链。

免费Yahoo图表接口已验证可返回DX-Y.NYB原始日线，属于第三方指数行情，不称ICE直接授权数据。适配器须同时核对symbol、instrumentType=INDEX、日频及纽约时区；保留原始OHLC/timestamp，排除纽约当天临时bar，全空槽不补值，部分空或身份异常拒绝，未知volume不填0。独立存储与真实取得截止可查询修订；不得把广义美元、美元期货或AI分析接入同一精确DXY链。

## 官方文件入库

网页已取得且证明来源的WGC/ALFRED原件可以通过项目受管收件箱交唯一collector摄入；probe数据库不能导入。先核对登记来源、原件SHA、真实取得时间、结构和字段口径，原子发布内容寻址文件及manifest，每文件数据与导入检查点同事务。收件箱扫描成功、正式入库、网站自动下载是三项不同结论；分别报告取得/导入与外部更新任务的最后检查、下次执行和失败状态，不新增重复定时。

ALFRED按来源版本身份独立存储，避免整份历史A→B重导又追加A→B，或同名FRED/ALFRED进入研究后重复计数。保留NULL、日精度realtime起止及开放结束；as_of约束本项目真实取得时刻，vintage_on只选择来源日历日期，不补造发布时间。多档案按UTC实际时刻排序而不是原始带偏移字符串；后到的更早文件不能静默覆盖。WGC保留季度和当前发布版本，核对主表与独立摘要表、负值及季度连续性。验收用重复摄入、重启、事务中断和两个时间轴的实际查询。

用户要求长期浏览器或不定期更新时，使用独立固定值守任务与产品heartbeat；先查已有职责，确认真实任务ID、初始化、浏览器登记及实际代码版本，绑定后回读类型/目标/状态/下次时间，并完成一轮获取→入库→清理，不能把创建或初始化称自动化已验收。正常无变化保持安静，已确认官方发布日期临近时可按授权调整核验窗口，成功后恢复基础频率。网络/构建仍沿项目唯一受限worker，数据库仍由原collector写。

清理在正式导入检查点及持久压缩原件哈希均通过后进行。仅删除本轮已知下载副本、工作副本，以及不再被未消费manifest引用的收件箱原件；先核对全部候选hash，浏览器文件另核对路径、inode和mtime。保留规范数据、版本、压缩原件、来源时间/hash和小回执；未入库、来源未知、内容变化不清理，不扫描删除全局Downloads、Cookie或其他项目缓存。清理操作应可重复执行。

## 时间与报告

观察期、计划发布时间、可证实公布时间和真实取得时间分开。当前修订历史首次取得于本项目采集时，不伪造点时历史。查询截止的等号和UTC语义按项目契约统一；行情修订后仍应可恢复截止时已知旧版本，快照与参数不覆盖。

官方日历按实际结构解析：BLS 的 iCalendar 保留时区，BEA 核对事件与时间所属行，Fed 多日会议取公告对应日期；来源仅有日期时保留 date_only，不补造发布时分，也不进入要求精确时刻的风险窗口。会议总表和官方月历可能精度不同，月历钟点须结合可核验的时区依据；表格解析保留真实表头做回归，防止跨列匹配污染首条事件。只投影目标事件日期/时间及修订版本，不顺带采入实际值或预测值。官方通常发布规律可用于提高核验频率，但不能填成逐条实际published_at。区分官方已公布、转载来源已同步和本项目已采到；未知节假日/改期不造固定周数。用户已明确优先新数据及时获取时，历史精确时间与ALFRED旧vintage作为可选研究限制，不继续升级成采集门槛。策略鲁棒性、权重与边际效应遵循用户后续逻辑/回测契约，不因数据齐备自行配置。

覆盖报告从一致只读快照列来源、口径/单位、首尾日期、行数、边界、缺口、新鲜度及来源能力未核实项。各周期分别列最后bar起止时间；小时分页已提交不代表4H/日线聚合已追平，不用一个总截止时间掩盖差异。广义美元代理不能称精确 DXY，单基金持仓不能称全球央行净购金，非商业 COT 不能称 managed money；不绕过 Goldhub 下载策略。技术位置和宏观描述不输出未经确定权重的可执行交易指令。

## 研究数据交付

用户明确授权历史研究时，可以在已登记来源内扩展独立研究窗口，保留各源实际首尾日期、原始压缩响应或明确目标投影及完整响应hash；不要因请求起点一致就称覆盖一致。逐源成功检查点经hash核对后复用；成功页须自身携带 continuation，恢复时可从已归档页推进游标，避免归档成功而游标未写的中断使回补停住。校验归档投影与检查点全部数据字段一致，失败按持久retry_at仅续缺失来源；研究输入不得导回正式库或另开collector。导出运行库使用只读事务取得一致视图，避免复用实际会写入研究记录的snapshot入口。

时间/单位必须在交付时可复算：来源历史版本与当前修订分别命名，NULL修订撤销旧值；COT跨零头寸用数量差，不能直接算收益率；SOFR−IORB使用同观察日。用户指定人民币现金流时，单独登记汇率参考和USDT/USD假设，不把人民币视为USDT；DEXCHUS 等估值数据与预测因子清单分开，持续更新不自动增加模型因子。参考汇率不冒充实际兑换成交。保留每笔外部入金、兑换成本、内部买卖及期末清算，基准保持同日同额同成本。小额分批按真实最小委托和步长处理，可合并当时合格的现金批次后成交，但须逐批归因；重复检查不能增加累计额度，新入金不能归作卖出回补收益。当前委托规则用于历史时明确为执行约束假设，并保留连续数量对照。

研究候选在查看绩效前版本化，全部失败场景保留；后续用户改变资金或周期口径应新建研究版本，不覆盖旧结果。多周期标签从允许的成交时点起算，训练仅纳入到拟合时已成熟的标签；输入只引用已闭合连续bar，缺口/过期保留UNKNOWN。不同训练频率使用一致归一化损失的收缩口径；宏观前填不增加独立信息组，训练残差尺度不能称为已校准的预测区间；参数、状态与响应函数的消融须一次只改变声明的对象，复合方案比较明确包含哪些变化。阶段描述和未来条件关联不是预测正确率，减少回撤不等于跑赢持有。完整归档与图表核验后，只清理本轮临时依赖/缓存和可重建副本，保留规范输入与小回执。业务数值规则归项目，不固化进技能。

## 发布与核验

从已提交源码和锁文件构建独立不可变 release，校验安装包字节、manifest、非 root 账号、配置/数据根与只读绑定。既有发布升级必须核对 expected-current，保留原 release 和新增数据；部署脚本的阶段回执决定能否接续，不能从非零退出推定尚未切换。

变更systemd单元时核对旧/新精确哈希并备份；尤其simple→notify后，回退旧代码须一并恢复匹配的单元及配置，否则旧代码不发READY会卡在启动。回退只恢复本次目标，不删新增表、数据、版本或持久退避。

浏览器更新器可独立从精确Git archive与锁文件发布，校验安装源码和manifest后原子切专属updater入口；只读公开代码按实际执行用户授予最小目录通行权限。适配更新器不必重启未变的collector，分别回读两个组件版本/PID和回退点；构建缓存发布验证后按本轮精确路径清理。

停止 target 返回后，子服务可能仍在 deactivating；有界等到它们 inactive/MainPID0，再核对 Result。API 正常 SIGTERM 与采集正常退出都须结合实际 Result 判断。停止后无写者且 WAL 不存在/为空时，稳定数据库可用 mode=ro&immutable=1 读取，避免只读挂载上的 WAL 辅助文件创建；运行中的库不能用 immutable 绕过 WAL。

正式核验包括：发布字节一致、各服务唯一进程、旧路径在实际服务 mount namespace 不可读、API 无认证挂载、只允许读取、原数据库/检查点保留、停止与恢复实际成功。systemctl 对复杂凭据属性显示 [unprintable] 不是凭据已挂载，必要时用公开 D-Bus 属性的数组长度核对，永不输出值。离线测试、来源 probe、服务健康和完整覆盖分别报告，不相互替代。
