# Windows 计划任务管理

## 适用范围

使用本 skill 处理以下请求：

- 只读盘点或审计 Windows 计划任务。
- 为本机开发项目创建、更新、启停或精确卸载计划任务。
- 诊断后台任务闪窗、Python 启动器、触发器、权限、重复实例或遗留子进程。
- 建立或核对项目任务清单、安装脚本、查看脚本和卸载脚本。

系统、Windows、硬件厂商和已安装软件自行维护的任务只能只读识别，不得纳入项目重命名、迁移或删除。

## 授权边界

1. 查看、诊断、审计只授权只读操作。可运行本 skill 的盘点脚本和系统只读查询，不得顺带启停、修复或重建任务。
2. 当前用户在当前消息中明确指定目标、范围和创建、更新、启停或删除动作时，视为已授权该范围及必要的实施、回读和生命周期验证步骤，不重复逐项确认。
3. 只有对象或范围存在实质歧义，或动作可能造成重大且难以恢复的损失时，汇总精确对象、影响和恢复方式，最多确认一次；确认后按同一范围完成。
4. 使用管理员权限、迁移为 Windows 服务、读取凭据、生产写入、真实交易或扩大到未指定任务，均视为新的实质范围，必须有当前用户明确授权并继续遵守对应专项门禁。

## 资源加载

- 只读盘点可以直接运行 `scripts/show-development-windows-tasks.ps1`。
- 创建、更新、启停、删除或登记任务前，必须读取 `references/task-lifecycle.md`。
- 涉及 Python、后台常驻或“无窗口/不闪窗”时，还必须读取 `references/background-python.md`。

## 主流程

1. **解析对象与权限**：读取目标项目的 `AGENTS.md`、任务清单和已有生命周期脚本；确认请求是只读还是变更，并解析精确 `TaskPath + TaskName`。
2. **只读盘点**：枚举现有任务，核对相同动作入口、工作目录、触发器、运行账户、当前状态和动作文件复用关系；优先原位维护同一任务。
   - 同时区分项目清单中的静态目录、任务动作的实际运行目录（WorkingDirectory）和运行中进程的 CurrentDirectory。三者不一致时记录实际值与影响，不用项目根目录名代替运行目录。
   - 对更新任务，先只读确认目标程序是否活动。目标活动时只登记延期，不结束进程、不重启桌面端、不强行覆盖文件。
3. **冻结事实源**：新任务先确定稳定的 `project_key`、`project_code` 和项目内编号；已有任务以项目清单和本机实例双向回读为准。归属不明或旧格式任务只标记为 `legacy_unregistered`。
4. **备份并实施**：先保存 XML 或结构摘要，只通过项目提供的精确生命周期脚本或精确身份实施；禁止前缀、通配符和模糊匹配变更。
5. **回读与验证**：核对动作路径、参数、工作目录、主体、触发器、设置和状态。实质创建或更新后完成一次适合该任务的启动、停止或重启生命周期检查，并核对进程、端口、健康接口或数据水位。更新任务必须把“检查无更新、更新已应用、因活动目标延期”三种结果与失败/结果未知分开回读。
6. **更新清单**：让项目任务清单与本机实例一致，记录安装、更新、卸载和回滚入口；只有证据完整时才报告完成。

## 只读盘点

从 skill 根目录运行：

```powershell
& .\scripts\show-development-windows-tasks.ps1 -Scope Project
& .\scripts\show-development-windows-tasks.ps1 -Scope Development -AsJson
```

脚本仅调用计划任务读取接口，并审计任务归属、动作、触发器、状态和 Python 无窗口启动器；不得为了测试它而创建、修改、启停或删除任何任务。

## 强制规则

- “无窗口”验收覆盖任务进程及其全部后代进程；不得只验证根进程名。子进程可使用 GUI 子系统，或由父进程以受验证的无控制台创建方式启动；不得出现新的 OpenConsole.exe、conhost.exe 或 WindowsTerminal.exe，也不得用 Shell 套壳掩盖子进程窗口。
- 任务清单中的静态项目目录、任务动作 WorkingDirectory、脚本所在目录和进程 CurrentDirectory 必须分别记录；工作目录缺失或被重定向时停止变更。
- 更新前发现目标程序正在运行时，结果必须是 deferred_active_target，并记录下一次检查/重试条件；不杀进程、不重启、不自动回放。
- 更新回执至少包含唯一任务身份、主机、UTC 运行时间和不可复用的 run_id。回执超时或传输中断后先按完整 TaskPath + TaskName、目标版本/哈希和日志精确 readback，标记 result_unknown，不得盲目重跑。
- 多主机或批量运行必须每个主机写入唯一、不可覆盖的回执；不能让不同主机共用固定文件名，也不能用最后一个回执覆盖前一主机结果。

- 任务身份始终是 `TaskPath + TaskName`，显示名、脚本名或描述不能替代。
- 新任务默认使用当前交互用户、`Interactive` 和 `Limited` 权限；只有确需管理员能力且当前用户明确授权时才使用 `Highest`。
- 只改说明时不得顺带启停、重建、改身份或改触发器。
- 删除前核对是否正在运行、动作是否被其他任务复用，并保留可恢复的 XML 或结构摘要。
- 不把 `TaskHidden=true` 当作无闪窗证据；Python 后台任务必须按参考文件核验 PE 子系统、启动器哈希和进程生命周期。
- 不使用 `powershell.exe`、`cmd.exe` 或 `wscript.exe + VBS` 作为掩盖控制台的套壳。

## 交付证据

交付时至少说明：精确任务身份、主机、修改字段、备份位置、清单位置、实际运行目录与静态目录、更新结果类别、回读结果和生命周期验证结果。若只完成盘点，明确说明未对计划任务做任何变更。
