# 项目任务交接包模板

创建后继任务前，把当前事实压缩为以下结构。通常控制在约 3,000 个中文字符内；复杂项目宁可引用项目文件，也不要复制完整聊天或长日志。

## 项目身份

- 项目名称与保存项目：
- 当前目录与 Git 分支：
- 项目长期目标：
- 当前阶段：

## 当前有效规则

- 全局规则：只写与本项目直接相关的约束。
- 项目规则：列出 `AGENTS.md`、唯一计划或契约文件。
- 安全与权限边界：写清不可自动扩大的动作。

## 已完成与证据

- 已完成事项：
- 变更文件或提交：
- 已运行验证及结果：
- 当前服务、端口或后台任务：

每项标明“本轮已回读”或“来自旧任务、需复核”。不要把计划写成已完成。

- 已修改未提交：
- 新增未跟踪：
- 与用户既有改动重叠处：
- 不得清理或覆盖的内容：

## 未完成工作

- 待办与优先级：
- 阻塞或待用户决定：
- 已尝试但失败的方案：
- 建议下一步：

## 后继任务启动指令

- 首先读取适用规则、项目计划和当前 Git 状态。
- 对照本交接包报告差异；易变化状态必须重新验证。
- 未附带首项任务时只完成初始化并等待，不修改项目。
- 已附带首项任务时，在核验完成后按其授权范围继续。

## 排除内容

不写入凭据、令牌、Cookie、`.env` 内容、私有会话标识、完整终端输出、完整旧对话或与项目无关的个人信息。
