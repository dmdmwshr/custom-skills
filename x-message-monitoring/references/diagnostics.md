# 按需诊断

自动化可以主动尝试自行修复，不因普通可恢复异常立即等待人工。先核对实际回执与原因，优先使用现有受管入口完成补查、刷新引用、核验目标后的有界重试、原资料连接恢复、断点续接及漏换代补办；沿用各操作原有次数和总预算，不通过反复新建周期重置预算。确需局部代码或配置修补时，仅修改有直接证据支持的当前故障原因，保留恢复点，完成相关验证并遵守单写者及受管发布流程；验证失败回退本次改动。不得顺带重构、升级依赖、修改或发布Skill、扩大采集/外发范围，或以通过为目的放宽身份/完整性校验、无限延长超时、改变筛选/关联/留存/去重规则、重置水位及切换账号或控制技术。已授权的正常换代和受管恢复不属于扩大修改。结果未知先对账，不能重放通知或手清标记。无新证据、达到原预算，或修复需要扩大范围/无法安全验证时，停止该项修补，记录原因、尝试、变更与回退、验证及断点，继续独立项并由后续正常周期接续；真正需人工的部分再明确报告。

先定位实际失败层：模型/字段、采集结构、浏览器控制、进程身份、账本或投递。不要因同一拒绝码不断加补丁或重跑整轮；先检查是否把显示差异错误当成内容变化。

先看已安装 workflow.state().last.recovery、实际提交标记及 adapter 回执，再决定续行：未提交的字段/顺序错误可就地更正；已返回的目标提取失败由 driver 在同页有限刷新重读；仍无法解析的引用记 unresolved 并交给模型评估其余证据，不停止无关消息。not_unique 未提供数量时不猜零个或多个，也不选第一条冒充唯一身份。控制/外发 unknown 只对账，不能以通用 retry 重放。单次恢复预算耗尽后分析新证据，按已安装入口正常收口并从未完成段接续；无新证据时保存缺口待正常周期，不盲目重放整轮，也不自动暂停调度。实质异常及恢复结果写入项目问题记录，供人工后续优化Skill；普通周期不自行发布Skill。

成员等待超时不等于没有回复关系。核对同次 requested_target、等待阶段、结构元数据和 failureEvidence；页面可能暂未完成加载，或父帖被虚拟化到视口上方。已安装恢复版本在原期限内按实测结构向上补查，已知未就绪最多一次在原页重新导航精确请求URL，合计30秒；不能只reload实际停留的上一条状态。请求返回后仍校验真实URL/目标身份，不以已写入的lastUrl代替页面事实；即使下方回复已满足成员数量，提取后的上文缺失仍须检查。身份冲突和控制unknown不得套用此恢复。用户告知曾操作页面不等于持续人工接管：先重新核验页面身份、执行者及在途回执；旧观察失效但控制已知且无并发时，可自行更新观察或正常释放后新鲜接续，不要求再次确认人工结束，不关闭整个自动化。明确人工模式或正在并发控制时串行避让。人工操作后的页面变化不能反推人工之前的错误原因。具体页面根因不能仅由事后正常截图推断，恢复验证和原故障证据分开记录。

引用超时先比较外层工具期限、整项预算和目标页等待段；segments=0 / requested_timeout_ms=0 表示等待尚未执行，不能判为网站加载慢。quote_budget、read_recovery、quote_evidence必须保留在紧凑结果中。已安装恢复驱动为原帖定位、引用点击、目标/展开分别分配有界阶段，并共享整项上限；受管回执确认前次已结束才最多一次恢复。精确引用URL已知则重新导航，链接未知则回到核验过的原帖重新观察并重新定位，不能把错误落地页当预期ID或沿用旧坐标。真实unknown不恢复重放。表面/目标/正文的已知局部超时转unresolved，保留原因并继续独立项；workflow_stream_stopped不是新一轮浏览器尝试，不循环调用已停止流。区分预算耗尽、等待超时、跳转不符、登录身份与控制未知，用户可见类型和状态中文化。

quote_context_incomplete 在 collect 发送前发生时，继续 quoteBatch 至 done、复核上下文后再 collect；不是重新发送请求。给用户报告时说明已尝试的恢复、剩余缺口和后续复评，而非仅粘贴拒绝码。诊断和模型结论分别留证。

跳转不等于正文已完整展开。已观察的全文按钮仍在屏幕外时，由已安装 driver 按真实几何在同页有限滚动，每次重新核验同一来源身份/UTC/正文后才点击；父帖自己的页面不能重新选择回复对象，保留原已验证父子边。不要人工猜坐标、默认点引用卡中心或滚动不明页面，也不为每个帖子机械滚到底。原文已在DOM完整取得不要求其每一行都进入视口。源码/隔离测试证明的缺口与具体真实漏判根因分开报告，仍需受影响的实际验收。
正文差异使用同轮 contentReview 完整上下文由模型判断。需要代码修复时保留同次比较的差异位置、有限片段/码点和身份元数据；不补读失败页或恢复已清正文。
raw_html_rejected 可对同次 kept payload 调用 diagnosePayloadText 一次；它只读当前内存，不重新 draft/raw、发送或读 DOM。其他 probe/readiness/expander 证据直接保留本次回执，不能凭摘要遗漏再执行。
heartbeat_collection_time_invalid 核对真实 preflight、collectedAt 和时钟；elapsed_ms 为负及 WSL Time jumped backwards 是真实时钟线索。已安装代码仅同请求最多一秒 monotonic 等待 UTC 追上，不能改时间、重投或扩大预算。
新进程租约或执行者登记缺失按 [受管登记](wsl-migration.md)，不误报为 X 未登录。已返回的业务拒绝与超时/坏回执的控制 unknown 分开处理。
共享 Playwright 连接缺失由已安装入口列举并建立唯一连接；已知上下文丢失只在初次绑定前有限退役重建，不重放页面动作。真正 pending/unknown 先按精确回执对账，不能仅因超时清除。环境ready在产品暂停/恢复后报文件身份错误时，检查该自动化配置的实际属主/权限；产品可能按进程umask重写为组可写。只修精确目标并验证下一次产品更新仍保持受管权限，不放宽root读取门禁或手写调度内容。
准入失败应关闭未使用的逻辑客户端；已知本地预检错误保留原错误码，不错误升级为控制未知。新进程持真实身份重新取得互斥租约，不复制旧 grant。诊断保留终端异常码或受管校验点，不从traceback文件名提取错误、也不把通用身份拒绝直接猜成时钟或登录故障。
真正 unknown 保留原请求/在途/守卫审计，停止依赖动作；控制子进程死亡但父进程存活须按实际PID/start/退出状态区分，不能当普通网页超时。当地受管入口已支持死亡观察执行器退役时，核对精确请求、代次与原浏览器身份，保留原结果unknown且不重放，然后新鲜观察；业务已终结且runtime进程已退出时由受管管理入口核验并归档对应守卫，不能手删。SIGABRT不自动等于内存不足，缺少stderr时准确记录原因未明并补退出诊断。独立修补遵循本页最小自修边界。恢复须基于新证据，不复制旧 grant、clear unknown 或套用已消费窗口。
新增诊断需真实 driver/adapter/共享接口贯通测试；纯 mock 或离线成功不代表实机通过。当前获准执行者的有界新诊断不计业务周期，正常收尾后再做针对修复的一次真实验证。
diagnoseQuote 专用于含直接引用的来源，不是普通回复/祖先链读取入口。普通回复的 quote_container_missing 不能证明上下文不可读；来源作者应与独立诊断cycle.account相符，但不得因此改业务账号。permalink_target_status_not_unique 可表示零个或多个有效身份，若回执未提供匹配数则不得猜测；引用预览作者与外层作者分开报告。诊断失败后 guard 停止，未执行的第二目标不算已观察；新诊断须有明确范围，不能为绕过停止标记盲重读。

新增共享诊断优先走注册reader/adapter；若直接使用受管宿主operation元数据，返回必须满足其类型信封，不把裸DOM结果当作有效primitive回执。信封不匹配造成结果未知时保留原请求，核对精确操作和执行者是否结束后经受管reconcile处理，不重放请求或从丢失结果制造业务事实。

历史窗口结算与常规采集是两个阶段。常规流已完成时仍可结算完整历史覆盖，但必须保持已完成流计数和通知不变、验证水位与窗口基线；不能反复调用旧逐帖分析去绕过历史结算拒绝。结算报错先定位确定性合同，错误已知不报成控制超时。
