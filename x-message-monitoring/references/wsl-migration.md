# WSL 身份、受管加载与发布

当前运行状态和固定任务绑定看业务仓 PROJECT_HANDOFF.md；源码、发布、数据和管理入口读取当地项目部署说明。本文不保存用户名、UID、安装路径、任务ID或易过期的 PID/session/版本快照。中枢只沿已绑定出口投递，不从入站另建扫描者。

Skill负责业务流程，项目负责业务实现，电脑环境负责浏览器及权限/服务生命周期。普通运行使用登记的非root用户；系统安装和必要特权操作通过环境受管入口完成。不同用户各自部署资料与凭据，配置可迁移不等于登录态可复制或另一用户已验收。

## 正常进程重建

先调用当地环境ready入口，环境层编排已知冷启动、依赖服务和接续；健康实例返回复用，不重新启动。需要暂停原调度时仅用产品工具，记录原状态，只恢复本次自己暂停的ACTIVE；原本PAUSED保持。过渡态按环境返回的continuation回读并继续尚未执行的步骤，命令未知只检查，不重复start/resume。环境就绪不替代当前任务身份和页面归属；按需接续不是已证明所有主机自启动，下一次自然重启的完整路径另作观察。

使用当地已接受的身份接续入口，具体固定代码只从项目 LINUX_STARTUP_GUARD.md 读取。全新内核不继承旧变量；每轮使用块内局部绑定。已有证明重新核验活进程和官方回执；正常续期由环境代码判断，不每轮人工刷新。
新进程使用环境提供的固定 prepare/complete：原样调用 prepare，若已verified直接继续；需要登记时等prepare工具完成，紧接下一次工具complete。入口保存的是已完成prepare的官方turn/call，不是complete自身尚在进行的call。不要改写受审代码、手抄调用ID、扫描停泊journal或手工重建证明。环境层按精确任务/轮次有界翻页读取回执，核验当前boot/进程及见证FD并自动校验最新停泊及无后续活动；回执超出首屏不等于不存在，超过范围或期限仍明确拒绝。
当前已验证官方 node_repl/js，也保留旧 cua_repl/js 回执兼容；不能从工具名称相似推定进程链相同。不得复制旧证明、修改 task_id 环境或读取失败正文。尚未登记的本进程见证只有经固定入口验证后才能重新观察并产生新鲜官方回执；不关闭/替换旧见证，不放宽已过期grant或unknown。
逻辑任务登记与临时PID/连接/租约分开：进程正常退出后的旧证明只作审计，新进程取得新鲜证明后接续；更换固定任务本身通过明确交接更新登记，不能冒用旧任务。身份门禁不应要求旧进程或旧变量永久存在。
同进程上一turn登记中断时，固定入口在原锁内只读核对：已登记且验证通过则复用；明确未登记、无在途、known停泊且进程一致才允许新turn生成新鲜prepare，不重复旧complete。只替换过时JS步骤记录，不清控制unknown/审计。忙锁、已过期、身份漂移、结果未知或旧执行者仍活动不能当普通重建。候选未安装时完成受管部署，不调用不存在的 API。具体参数与首次启用状态见项目当前说明。

## 加载与页面

只加载部署入口指向的已接受模块。加载代码由项目当前 LINUX_STARTUP_GUARD.md 提供；遵循实际官方工具的模块能力，不为旧脚本切换或取消工具限制。launch 返回立即保存，不能先后处理失败而丢失守卫。
固定 driver IIFE 返回对象，stdin/control IIFE 返回 factory；版本在 factory 核对。配对守卫连续覆盖准备到正常关闭，Python 正式入口另持同一共享锁，不自动删 marker。
hidden_chrome_mcp_adapter.js 直接导出 connect；连接后使用 adapter.driver。一个物理 MCP 连接/真实工作页，逻辑客户端逐轮更换，reuseTab 不按标题或 URL 认领未知页，park 不执行物理关闭。
正常重启由电脑环境负责已知停泊退役、服务就绪和新句柄核验；不是重新走历史维修。页面归属不明、仍在途或真正unknown不自动新页/重连；真正人工接管先排空断开，普通查看不等于接管。标签组名称不是额外页面。
元数据通过、MCP 控制、X 登录和业务成功分别记录。正式仅 hidden_chrome_mcp，旧 CLI/native/日常扩展/Python/Windows 启动路径均不调用。

## 开发与发布

模块测试按影响运行；完整整合后一次全回归。driver 分片构建 --check，两个 reader 精确哈希不变时复用原受审包和物理连接，不因文件组织变化重启浏览器。
runtime-files.json 显式白名单，维护工具/测试不入生产。沿 cc-connect-operations/scripts/upgrade_linux_runtime.py 的真实发布契约，用新的静止备份窗口；旧窗口不可重跑，不手动覆盖 current。
正式库仅 production_startup_guard＋SQLiteStore(read_only=True) 正常关闭，不能裸 mode=ro 或为消空 WAL 手删旁车。
暂停原 x 后受控切换，原 owner 一轮新鲜双流及受影响的新进程/单页复用验收通过即恢复同一两小时调度；长期观察不机械要求固定三加四轮。候选、安装、实际业务分别留证。回退本次程序/配置，不回滚新增业务事实。
