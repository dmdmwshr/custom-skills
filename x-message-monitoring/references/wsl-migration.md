# WSL 身份、受管加载与发布

当前事实读取项目 PROJECT_HANDOFF.md、LINUX_STARTUP_GUARD.md 及本机浏览器说明。本技能不固化用户名、UID、任务ID、PID或版本快照；旧 CUA/prepare/complete 证明不适用于当前 Playwright 路线。

## 身份和共享连接

生产调度任务与当前执行者分开。开发/验证可由当前已授权任务直接完成；统一部署登记保存阶段、生产任务、临时执行者、代次和项目根。使用当前工具真实任务元数据，不冒用生产任务。进程持有跨项目互斥租约，不能靠超时抢占仍活动的执行者。不同用户/资料的凭据不能复制或强行合并。

只通过已安装的项目入口加载 runtime，再 connectPlaywright。所有项目在相同受管工作目录复用一个物理 Playwright 连接；项目页面分别登记，操作串行。当前已验证官方 Playwright CLI 经扩展控制用户指定桌面 Chrome；不调用 GPT/CUA/native，不为每个任务另开物理连接。

正常 park 释放逻辑客户端与本轮业务守卫，保留有用途的页面。后续新进程从真实任务身份重新取得租约，并复用精确页面对象/ID；保存 reuseTab 返回的原始句柄，不能手造同 ID 对象。页面/上下文丢失不能按 URL/标题认领：仅已知无在途的绑定失败走受管有限恢复，归档旧连接元数据、断开后建立新连接，再重新观察。连接缺失与正常新进程续接已实测；整机重启和外部崩溃须按实际环境另验，不能据此声称全部通过。

未知请求持久保留，先对账不重放；明确完成的无副作用拒绝可凭精确回执结算，不一概永久阻断。恢复步骤回读已完成阶段，重复调用不重做已完成的退役/建立。用户页面和登录资料保留；废弃授权页按精确归属归档后关闭。

## 加载与收尾

只加载 current 指向的已接受模块，加载代码及签名见项目说明；不要复制旧维护代码或恢复正文。launch 返回立即保存，连接失败时正常释放未使用租约及守卫，不丢弃活跃对象。固定 driver IIFE 返回对象，stdin/control 返回 factory。首次进程或客户端变化完成真实自检。

配对守卫连续覆盖操作到正常关闭。正式业务由 workflow 完成 finish、终态 health、park、清事实、关闭守卫；诊断不得写业务，须依据实际无锁/零在途和停泊回执正常关闭。候选测试、安装、浏览器控制/登录、业务投递和用户已读分别报告。

## 发布与初始化

模块测试按影响，整合后一次回归；driver 分片构建 --check，reader未改则复用原精确证据。runtime-files.json 是显式清单，测试和维护脚本不进生产。

暂停原调度，仅用产品自动化工具；用新鲜静止双库备份窗口及现行受管发布入口，不手改 current 或重用已消费窗口。正式库只经 production_startup_guard 与 SQLiteStore(read_only=True) 正常关闭。回退本次程序/配置，保留之后新增业务数据。

用户明确要求全新初始化时才清历史：固定用户指定起点，先新鲜核验双流边界，再匹配双库备份，清 X 执行/去重/投递及中枢精确 X 历史；保留配置、绑定、其他项目及平台消息。保留外部引用的单调序列，新告警事件编号也必须从该序列延续，避免撞上中枢历史隔离键。备份不是新业务事实来源；历史是否重新通知按用户明确选择。

当前获准执行者完成新鲜双流、真实投递与增量防重，正常释放临时权限后交还生产任务并恢复原调度。不要强制原任务重复验收，不恢复已退役自动化；长期自然观察不是固定三加四轮的发布门槛。
