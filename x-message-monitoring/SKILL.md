# X 消息监控

当前驱动 3.0.20、标准输入客户端 1.0.0、步骤修订 2026-09-09.6；原固定任务使用用户指定的 Luna/max。主列与目标就绪在原十五秒页面预算内分段等待，页面失败不续读；水位原样提取、分页自动判断、回复最多八导航保持。上下文整理后的静态绑定核对与步骤准备在 acquire 前完成；连续手动验收整组回传后再整理。有界故障定位仅在已授权维护时读取 [维护诊断](references/diagnostics.md)。

运行只在已登记的唯一 Desktop 固定会话；维护和离线测试可在开发任务完成，不代替固定会话进行真实扫描。

1. 完整读取 [固定快速路径](references/fast-path-runbook.md)，按固定入口执行。普通轮次不再展开历史、搜索模块、生成浏览器采集代码或试探 API。规则/驱动版本变化或未知契约才读取 [完整边界](references/heartbeat-and-delivery.md)。
2. 浏览器代码唯一来源为业务项目 `scripts/desktop_monitor_driver.js`。在受支持的 CUA 会话中用普通 `let` 绑定加载原样工厂一次；版本未变、会话未重置即复用。不得使用 `globalThis`、内部模块、独立浏览器控制进程或自建浏览器桥接。用户已批准宿主通过 `scripts/desktop_stdin_client.js` 向原固定校验入口的有限子进程直传标准输入；它不控制浏览器。
3. 流程固定：健康 → 锁与预检 → 主帖采集/分析/提交/登记 → 回复采集/分析/提交/登记 → `heartbeat-finish`。主帖和回复各自事务；回复失败不回滚已提交主帖。共同身份/路由故障停止后续处理。
4. Chrome 优先；仅实例、扩展、登录不可用三类实测失败，经机器授权才用 Edge。结构、水位、父帖歧义不得换浏览器。只操作本轮新标签，不触碰原有标签，不读取密码、Cookie、令牌、浏览器存储或验证码，不保存 HTML、截图、HAR。
5. 两流先草稿 → `context-plan` 只读识别新项 → 补必要上下文与一层引用 → 一次冻结 → collect-stream → analysis-plan → scan-analysis。新回复直接 Latest 搜索和永久链接核验，上文最多三层，每条最多五个引用来源，同轮复用来源；按 [上下文与额度契约](references/reply-reset-contract.md) 执行，`reply-context-plan` 仅保留兼容。程序组装 V3，不重写映射代码，不重新分析历史记录。
6. 主帖和回复统一只推送 Codex 额度重置相关的新内容；包括进展、延期、规则和明确否认，相关无时间写明未提供可推算时间。通知分别展示当前消息、直接对象和采用的上文/引用的原文、翻译、时间与链接；引用不能冒充外层作者承诺，其他产品重置不推送。无关/无法判断入账并推进水位，未知送达不重发。
7. 唯一完成依据是 `heartbeat-finish`：完整成功且机器允许才输出精确 `DONT_NOTIFY`。部分完成或未知回执报告简短中文故障。连续四次完整、零可推送的**定时运行**由 SQLite 生成飞书健康证明；手动验收不充数。
8. 保留现有固定任务、自动化身份与计划、工作目录；本任务模型按用户指定 Luna/max。不得新建、唤醒、转移、恢复或并行使用第二个 Codex 任务；cc-connect 只做 `direct_feishu`，入站 `silent_drop`，不创建 cc-connect cron、Windows 计划任务、飞书入口或第三种浏览器。
9. 每轮汇总浏览器到收口的全部失败阶段。首次、实质变化、持续满二十四小时一次、完整恢复一次由账本去重；每个失败周期仍在原任务报告。已经提交的流发生后续投递/回执/标签关闭错误，使用 cycle-failure 追加，不覆盖成功扫描或盲目重发。
10. 标准输入客户端 1.0.0 首次加载或控制会话重置后先完成固定 selfTest，实际 exact_match=true 才使用。完整搜索序列、机器指纹、草稿、计划、冻结事实和分析均保留于同一 CUA 宿主；五个指定动作通过现有 chunks/无回显协议一次性提交。传入后回执未知不重试，小型控制动作及同 lease 两阶段 finish 继续用原入口。模型只读取新项分析事实，不再转抄长字典或 gzip 载荷。

维护任务遇到浏览器启动错配置、扩展控制失败、工厂转写差异，或用户明确要求验证飞书网页登录复用时，调用 `codex-local-state-diagnostics` 的浏览器控制恢复流程。普通 heartbeat 仍只走本技能固定快速路径，不因这条维护入口增加浏览器、任务、重试、登录或发送权限；不要把控制失败误报为用户没有登录。
