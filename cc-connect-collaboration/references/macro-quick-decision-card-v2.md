# 宏观快速决策卡 V2

本契约用于把业务仓中的已确认宏观事实压缩为移动端一屏可读消息。它不改变 `DeliveryIntentV1`、路由、凭据或回执，不调用模型，也不把条件性影响升级为交易信号。

## 所有权与版本边界

- 业务仓拥有官方事实、核心指标注册表、比较口径、修订判断、最终正文、不可变信封和只读预览。
- V1 信封、历史回执、过期项和未知状态保持不可变且不重新入队；V2 只处理独立切换水位之后的新自然事件。
- V2 引用固定为 `macro_notification_envelopes_v2:<sha256>`；完整事实与展示正文共同进入哈希。部署后的模板变化不得改写已冻结消息。
- cc-connect 只验证 V2 结构、内容哈希、严格 UTF-8、1—5 个指标和 700 字上限，再逐字传输 `mobile_text`。它不解释 CPI/PCE，不生成结论，也不保存正文。

## OKXnew 首期核心指标

| 事件 | 核心展示 |
| --- | --- |
| CPI | 总体与核心 CPI 环比、同比 |
| 就业 | 非农新增、失业率、平均时薪环比/同比 |
| GDP | 实际 GDP 年化增速、消费、私人投资 |
| 个人收入与支出 | PCE、核心 PCE 环比/同比、个人支出、实际可支配收入、储蓄率 |
| 零售销售 | 环比、同比 |
| FOMC | 目标利率区间及相对上次会议变化 |

BEA 继续使用既有凭据池、串行限速和同一批次持久化：GDP `T10101`、个人收入与支出 `T20600`、PCE 价格指数 `T20804`、月度变化 `T20807`。只选择业务注册表明确登记的 PCE 与核心 PCE 行进入成品卡；表号和序列代码不得出现在飞书正文。官方依据为 [BEA 核心 PCE 说明](https://www.bea.gov/data/personal-consumption-expenditures-price-index-excluding-food-and-energy) 与 [BEA API 指南](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf)。

## 修订与抑制门禁

按同一序列、相同频率、相同季调口径和相邻可比报告期计算；缺失时写明原因并停止成品生成，不猜前值。

1. 来源发布时间、正文哈希、脚注或其他元数据变化，但所有核心数值未变：`metadata_only`，只审计，不外发。
2. 只有非核心组成项数值变化：`non_core_revision`，只进监控，不外发。
3. 任一核心指标真实数值变化：生成一次 `macro_revision_confirmed`；按该发布时点补齐其他核心指标，只对本批真正变化的指标写“原值 → 新值”。
4. 新接入序列造成历史报告补采：`historical_backfill`，只预览，不外发。
5. 必需核心指标缺失、报告期不连续或无同口径可比前值：`incomplete`，只展示缺失原因，不生成伪正文。
6. V2 切换水位前事实：`legacy_ignored`，只作只读历史预览，不补发。

同一来源批次返回多张表时必须按发布事件与报告期合并为一张卡。单一指标的后续修订也要从截至该修订时点的官方版本回放完整核心快照；不得因为未变化指标没有在本批重复返回就误判缺失。

## 冻结正文

正文不超过 700 个中文字符，固定包含：中文事件名、报告期与“首次发布/核心修订”、一句结论、最多五项关键数据、条件性影响、限制说明、中文来源、北京时间和业务入口。

- 不出现底层序列代码、`Level`、英文单位、原始相对路径或内部版本号。
- 条件性影响只由确定性规则生成：通胀升温/降温、就业增强/转弱、增长加快/放缓、利率上调/下调；冲突时写“信号分化”。
- 没有发布前冻结且合法的市场预期时，必须明确“不能判断是否超预期”；不得用搜索摘要、模型或发布后信息补造。
- 固定说明“不构成交易信号”，不得触发授权、下单、撤单、账户读取或模式切换。

## 无外发预览与验收

- 业务监控提供最近十条 `preview_only` 只读成品；完整事件直接展示冻结 `mobile_text`，不完整事件只显示缺失原因。
- 预览页面没有发送、重放、编辑或修改按钮。预览正文必须与受控解析器交给 cc-connect 的正文逐字一致。
- 上线前暂停直接分发，确认业务待发送、中枢已领取和在途均为零；保留历史 `delivery_unverified`，不得回队。
- 先完成官方刷新和无外发预览，再恢复 `active/direct_feishu`。不得用旧宏观记录重放测试新版展示；下一条自然合格事件只进入“自动推送信息”一次，交易授权聊天不得出现。
- `/send` 返回 200 仍只表示传输层接受；移动端是否可见由用户确认，没有可信平台回执时继续记 `delivery_unverified`。

## 最小测试集合

覆盖中文名称、月份/季度、单位、CPI/PCE 环比同比、就业、GDP、零售、FOMC、零值、缺期、混合信号和 700 字限制；回归元数据同值抑制、非核心修订抑制、单项核心修订补齐与旧值→新值、多表同批合并、V1 历史隔离、幂等、内容哈希、UTF-8、预览逐字一致、正文不落中枢账本及 `/send` 开始后未知不重发。
