# 通用下载传输与缓存规则

## 参数契约

下载器的必填参数是来源链接和绝对输出路径：

- `--url__：HTTPS 直链。若链接带临时签名或令牌，改用 `--url-stdin__。
- `--output__：最终文件的绝对路径。下载器不会覆盖已有不同文件。
- `--sha256__：可选的官方 SHA-256。对模型、安装包、可执行文件和依赖包应提供。
- `--probe-only__：验证来源 Range、空间和 SSH 直连，不创建缓存。
- `--execute__：唯一允许远端取块、本地写入和原子落盘的开关。

状态文件仅保留去除查询参数后的来源、来源身份哈希、ETag、大小、块校验值和输出路径，不保存完整签名链接。

## 传输保证

1. Meifu 只保留当前正在中转的分块，不要求保存完整大文件。
2. 每一块先由 Meifu SHA-256 校验，再由本机 SFTP `reget__ 断点续传并二次校验。
3. 本机仅在完整文件大小正确、可选官方 SHA-256 匹配后，才原子移动到最终位置。
4. 上游、SSH 或 SFTP 的临时网络故障返回“等待网络”，保留本机状态和远端当前块；源文件 4xx、空间不足、目标冲突与哈希不匹配则停止等待人工处理。

## Meifu 缓存生命周期

固定缓存根：

- `/root/.cache/comfyui-models__：既有 ComfyUI 队列。
- `/root/.cache/meifu-downloads__：通用下载器。

`meifu-download-cache-gc.timer__ 每小时运行一次。它只枚举上述根目录的一层任务文件夹，跳过符号链接，并遵守下列规则：

1. 最新文件活动时间超过 72 小时的任务文件夹被清理。
2. 清理后仍低于 8 GiB 可用空间时，按最早无活动任务继续回收，直到达到保留空间或没有可清理任务。
3. `--dry-run__ 只输出候选；实际删除仅发生在定时服务或显式非 dry-run 调用。
4. 清理器不会删除缓存根本身、其他目录、正在写入的近期分块或任何本机最终文件。

这些阈值可通过 systemd 服务环境变量调整；修改前先检查磁盘容量、现有任务与正在运行的传输。
