# 每周维护与资源控制

本流程只在用户已授权定期维护时执行。使用 Codex 当前会话的每周自动化；没有默认常驻服务，也不重叠创建 Windows 计划任务。既有任务先按名称、提示词及项目路径查重，修改后回读星期、时间、时区、启用状态和绑定会话。自动化执行不等于自然触发验收。

1. 读取项目规则、工作说明、正式资料库唯一交接和本机配置。D 盘为主资料，E 盘仅备份；E 离线或待同步不阻断 D 盘业务。核当前 Skill 发现、Python/PyMuPDF、Ego 入口和资源；运行 `maintenance.py plan`，区分本地错误、临近实施、缺 PDF、超过90天未核对及来源目录。计划只读，不证明官网已核对。
2. 沿唯一 `registry.json` 和上次查询水位，先复核目录及后续范围调整公告，再查到期标准、已发布新版和缺件。标准号、产品名称和目录公告都要查询；本周优先完成到期和已知变更，再按最久未核对顺序推进完整轮次。记录查询词、分页范围、成功/失败/尚未尝试及下一水位。未覆盖项目不得统一刷新日期，不以“本周无变化”宣称全库最新。
3. 浏览器默认 Ego，先读 Ego Skill；一个目标一个 TaskSpace，按官方指导逐轮保存完整 UTF-8 `.mjs` 脚本并复用页面，正常下载前等待 download 事件、同轮 saveAs 到专属工作目录。官方入口先弹出新页时，转到真实下载页核对状态，在实际下载控件处等待落盘；空白页和成功响应都不证明取得PDF。完整落盘前不重复点击、不关闭下载页。普通失败可修正原入口；只有当前明确指定备用或特殊用途才切换 Playwright 等备用。网站限制、登录或付费保留断点，不绕过或冒充逐份失败。完成后核本轮自建页面，`finish({keep:[]})` 回收本轮界面；未完成下载、用户控制或未知结果保留精确断点。
4. 新版、缺件和状态到期分别处理。官网日期到期仅触发复核，不自动把标准变为现行、废止或认证证书过期。部分替代保留旧版适用范围。认证范围由规则加后续公告共同决定；退出产品用 `certification.in_scope=false`、`scope_checked_at`、`scope_source`、`reason` 明确标记，原始产品及 PDF 保留在独立范围退出目录，不计当前认证产品统计。转换期限用 `conversion_deadline` 和 `conversion_source`，无证据留空。
5. 维护前冻结当前 registry、受影响索引、交接和本机配置的哈希及小体积恢复基线；不为每周任务复制整套 PDF。只将实际核实结果写入工作区候选 registry，然后 `library.py build`、`validate`；无变化不构建、不重下载。构建会校验所有标准元数据（包括无 PDF 项），将已入库的缺件待办转入 `research_history`，保留原失败原因；未解决的适用性、失败、未知结果保留。改路径逻辑首次验收用隔离合成库测迁移，日常不运行整库 `relocate-check`。
6. 运行后核正式资料哈希、副本、目录显示及刷新，分别报告新增 PDF、当前范围、真实缺件、未核实内容、D 盘维护和 E 盘备份。回读已有同步结果，不强制同步、启停或改方向；E 不一致明确记备份待同步。交接登记实际维护版本、文件摘要、结果、失败水位和资源收尾。只在有实际变化、失败或需用户处理时发送简洁结果。

## 本机配置与容量

配置沿 `%LOCALAPPDATA%/FireProductStandards/config.json`，包含 `root`、`work_dir`、`python`、`browser_cli: "ego-browser"`、可选 `resources`。`work_dir` 必须在正式资料库及 Skill 源仓之外，每次使用独立 `runs/<日期时间>`，不要复制正式 PDF 到多个临时目录。启动检查真实路径存在和解释器能导入 fitz，配置缺失不称为可维护。

`maintenance.py resources` 返回工作区实际占用与所在盘剩余。默认工作区预算2 GiB、单文件下载预算256 MiB、磁盘剩余至少5 GiB；下载前核已知 Content-Length、下载中核新增文件大小。超限只暂停受影响的下载或复制，元数据复核和现有资料读取继续；先核对精确可回收项。文件合理超出预算时记录原因并按当前用户授权调整，不隐藏失败。不要循环下载、逐页长期保存图片或每周整库打包；PDF逐页渲染检查后立即回收本轮可再生成渲染图，仅保留必要封面、末页及异常证据。

## 精确清理

清理仅针对专属 work_dir 内的显式清单。每条包含 `path`（相对路径）、`standard`、`sha256`、`state: "archived_verified"`、`archived_at`、`active: false`、`resumable: false`、`recovery_critical: false`。归档后默认保留7天。下载成功后由本轮记录精确路径和归档证据，不自动认领历史散落目录。

先 `maintenance.py cleanup --manifest <清单>` 预览，核对候选后在维护授权内加 `--apply`。脚本只删单个文件，并重新验证其哈希与仍在正式库的同一标准副本；不递归删除目录，不跨盘/越界，不删除原件、失败、未知、未完成下载、活动文件、恢复基线或唯一副本。未知文件保留并报告。清理回执保存删除清单和真实回收字节，0字节也如实记录。重复运行不会重复下载或删除新内容；清理清单和基线不自动删除。
