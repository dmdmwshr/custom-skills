# FlClash Windows 桌面 UI 按钮地图

## 证据边界

- 实测日期：2026-08-01。
- 实测版本：Windows 桌面版 `0.8.94+2026071102`。
- 实测方式：先用 `scripts/flclash_state.py` 建立脱敏运行态基线，再逐页读取 FlClash 窗口截图与可访问文本。
- 本轮只执行主导航、返回、搜索定位、滚动和窗口尺寸调整；未切换节点、模式、系统代理或 TUN，未测速、刷新、重置、添加、保存、清空、关闭连接、暂停或退出。
- 原始截图不进入仓库。`代理`、`请求`、`连接`、`配置`、按需运行等页面会出现用户环境中的节点标签、域名、IP、进程、配额或 SSID，文档只保存脱敏后的结构结论。

界面会随版本、窗口宽度和当前数据变化。本文件提供语义地图，不提供可复用坐标。

## 一、控件风险分级

| 等级 | 控件类型 | 只读盘点默认动作 |
|---|---|---|
| R0 纯导航 | 已确认的主导航、返回、搜索、滚动、窗口尺寸调整 | 允许；动作后重新截图确认页面标题 |
| R1 主动探测 | 网络检测、延迟测试、订阅刷新 | 默认不执行；会产生网络请求、成本或运行态刷新 |
| R2 运行态变更 | 节点/策略组选择、出站模式、系统代理、虚拟网卡/TUN、暂停、关闭单个或全部连接 | 必须由用户逐项明确授权，操作后回读 |
| R3 持久配置 | 添加/删除/更新 Profile、DNS 覆写、排除 SSID、附加规则、脚本、端口或控制器设置 | 必须明确目标、备份/预览并完成持久层与核心回读 |
| R4 终止或重置 | 关闭窗口、退出应用、重启、结束进程、页面重置按钮、来源不明的状态图标 | 盘点任务禁止；分别取得明确授权后才讨论 |

无标签图标一律按更高风险处理。即使图标外观像“返回”“刷新”或“菜单”，也应先通过可访问文本确认其名称与角色。

## 二、六个主页面

| 页面 | 当前可见能力 | 关键按钮/入口 | 盘点边界 |
|---|---|---|---|
| 仪表盘 | 网络速度、系统代理、虚拟网卡、出站模式、网络检测、流量统计、内网 IP | 系统代理开关、虚拟网卡开关；规则/全局/直连单选；顶部状态/编辑图标；右下运行时长/暂停形态按钮 | 开关、模式、网络检测和右下运行按钮都不是只读控件；顶部无标签状态图标不点击 |
| 代理 | 策略组标签、代理节点卡片、协议与延迟 | 搜索、视图/筛选类图标、更多菜单、右下延迟测试 | 点击组或节点会改变运行态并可能写回选择；测速属于 R1；节点标签不写入通用文档 |
| 配置 | Profile 卡片、用量/有效期/更新时间摘要 | 顶部刷新与排序/筛选图标、卡片更多菜单、右下添加配置 | 卡片点击可能切换活动 Profile；刷新可能下载并重新应用；菜单与添加进入持久变更流程 |
| 请求 | 最近请求、协议/目标、时间、进程、字节数、规则与策略标签 | 搜索、右下清理形态按钮 | 只观察；原始目标、IP、进程和路由标签属于敏感运行遥测；不清空 |
| 连接 | 活跃连接、持续时间、进程、上下行字节、规则与策略标签 | 搜索、顶部全部关闭、每行单连接关闭 | 关闭连接会中断业务流量；任何关闭按钮都需要精确授权 |
| 工具 | 进入“进阶配置” | 网络、按需运行、DNS、附加规则、脚本 | 入口本身可导航；子页的开关、添加、编辑和重置均按 R2/R3/R4 处理 |

## 三、进阶配置子页

### 1. 网络

当前页面提供：

- `系统代理` 开关；
- `排除域名`，说明为仅在系统代理启用时生效；
- `虚拟网卡` 开关，界面提示仅在管理员模式生效；
- `栈模式`，当前版本可显示诸如 `mixed` 的选中值。

此页没有显示 external controller。不要因为“网络”页未出现控制器就直接修改 `shared_preferences.json`；按当前版本继续在应用级常规设置或 Profile 覆写中定位，并以 UI/数据库/生成配置/核心四层回读为准。

### 2. 按需运行

当前页面显示 `排除 SSIDs`：连接到指定 SSID 的 Wi-Fi 时，FlClash 可自动切换应用运行状态，并提供 `添加` 入口。

- SSID 是环境信息，截图与报告中默认隐藏。
- `添加` 会进入新建规则流程，不是只读查看按钮。
- 自动切换运行状态可能影响代理连续性，新增或修改前必须让用户确认触发 SSID 与目标状态。

### 3. DNS

当前版本的 DNS 页包含：

- `覆写 DNS` 总开关，启用后覆盖 Profile 中的 DNS 选项；
- DNS 状态与监听地址；
- `使用 Hosts`、`使用系统 Hosts`、`IPv6`、`遵守规则`、`PreferH3`；
- DNS 模式、Fake-IP 范围与过滤；
- 默认域名服务器、域名服务器策略、域名服务器；
- Fallback、代理域名服务器、Fallback 过滤；
- GeoIP、GeoIP 代码、GeoSite、IP/CIDR 与域名类条目；
- 页面右上存在重置形态图标。

只读盘点不得点击任何开关、值行或重置图标。DNS 变更会影响全局解析路径，必须单独确认、预览并做解析与核心回读。

### 4. 附加规则

用于控制全局附加规则。空状态显示“暂无规则”，右上提供 `添加`。

- 添加、编辑、排序、启停或删除都属于持久配置。
- 规则列表可能包含目标域名、IP/CIDR 或策略组名，截图与输出按敏感配置处理。

### 5. 脚本

用于管理覆写脚本，列表显示脚本名称与启用/选择状态，右上提供 `添加`。

- 点击现有脚本会进入可编辑流程，不作为只读盘点动作。
- 脚本可重写生成配置；修改后必须核对脚本持久层、生成 `config.yaml` 与核心实际加载结果。

## 四、未实测边界

本轮未打开下列入口，因此不得把推测写成当前版本事实：

- 左下无稳定可访问标签的应用级菜单及其全部设置页；
- Profile 卡片详情与更多菜单；
- 新增配置、排除 SSID、附加规则或脚本的表单；
- 仪表盘顶部无标签状态/编辑图标；
- 代理页无标签视图/更多图标。

需要补测时，用户应明确允许“只打开表单/菜单但不保存、不应用、不切换开关”。若控件仍无法通过文本、角色和页面标题唯一确认，就停止，不改用邻近坐标试探。

## 五、只读 UI 盘点清单

1. 运行只读脚本并保存运行态哨兵：进程、系统代理、应用偏好 TUN、生成配置 TUN。
2. 列出并聚焦唯一 FlClash 窗口；窗口最小化时只恢复，不启动第二个实例。
3. 每页先截图，再用可访问文本定位主导航；页面变化后重新截图。
4. 只操作 R0；看到 R1-R4 控件只记录名称、作用与风险。
5. `请求`、`连接`、`代理`、`配置` 和按需运行页的原图仅放临时目录，不提交、不外发。
6. 回到任务开始时的页面；如调整过窗口尺寸，尽量恢复原状态。
7. 再次运行只读脚本，逐项比较运行态哨兵；任何不一致都停止并如实报告。
