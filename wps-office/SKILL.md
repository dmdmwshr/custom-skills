# WPS 桌面文档能力

执行平台为 Windows；WSL 是源码维护或已授权命令发起端，不代表 Linux WPS 可运行。使用已安装 WPS 自带的 `wpscli.exe`，不安装第三方 CLI，不运行内嵌 Skill 安装或登录命令，不管理账号、订阅或服务。

## 选择入口

| 需求 | 按需读取与执行 |
| --- | --- |
| 转换、PDF 页面/水印/压缩/加密、OCR、元数据 | [28 项命令](references/commands.md)，再读所需命令的选项和验证层级 |
| 检查真实入口、调用封装、输入输出和未知结果 | [运行契约](references/runtime.md)；封装仅 `catalog`、`probe`、`run` |
| 原生文档编辑、保存重开、窗口隔离、AI 校对 | 先判断实际能力和本次授权；获准后按 `native-gui-control`，不把 CLI 或 COM 方法定义当已验编辑器 |
| 金山个人云文档、分享/历史/同步，企业 WPS365 | `cloud-docs`；分别核平台账号与企业应用授权，不以桌面会员身份替代 |

本机任务优先评估已验证的 WPS 能力，实际采用遵守当前全局及用户指定入口。能力不足或无法满足范围时，说明具体缺口，按原授权使用官方文档、表格、演示、PDF 等格式工具；不扩为另一套通用 Office 编辑器。

## 调用清单

- [ ] 在真实 Windows 上先用 `catalog` 查命令，必要时用 `probe` 只读比对当前二进制版本和帮助；多版本不猜最新者。
- [ ] 输入明确绝对路径和顺序；显式 `outputKind`。输出放全新独占目录，不能复用已有目录，即使为空。密码只在本机 UTF-8 标准输入中临时提供。
- [ ] 云 OCR 在启动前核本次授权依据与输入 SHA-256；本机安装、登录或别的样本授权不能代替原件外传许可。已有本次明确授权直接使用。
- [ ] 每次用唯一 `runId`；主机级持久意图跨证据目录防重放。同号已有记录时只回读，不换号盲重试。
- [ ] 界面、COM 实例、转换和 AI 的临时暂停严格按当前用户约束保持；鼠标空闲、只读帮助成功或协议准入不恢复暂停范围。

## 结果与交付

封装按 JSONL 的真实完成路径收集文件、目录和 Markdown 资源；自动改名以回执为准，不删除旧目标。保留批次顺序、成功子项和未知范围。超时、非零退出、部分失败、缺产物或事件无法绑定均不报完整成功；只管理本次精确 CLI 子进程句柄，不结束共享 WPS 或进程树。

`process`、`commands`、`artifacts` 分别表示进程、原生命令和产物证据；`contentQuality=not-assessed` 始终表示还须核内容、关键数字、表格、页数与实际渲染。元数据查询不是 OCR 鉴定；OCR 不是 AI 校对。不要将历史原生样本成功当作新封装已实跑。

CAD 回转缺图的内容失败、OCR 字符/排版变化、图片转 PDF 的解析器兼容差异、CAJ 无样本，以及新封装真实转换、COM/窗口隔离/AI 未测层级，按命令表和任务证据如实保留。一次安装发现或离线夹具通过不证明全部会员功能可用。
