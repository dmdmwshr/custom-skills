# AI 视频与多媒体创作管理

## 生产原则

把生成式视频视为“可追溯的素材生产”，而非一次提示词的成片赌注。每次决策都要能回答：依据什么事实、用了哪些资产、哪个工作流生成、为什么采用或淘汰。

不要把“电影感”固定为单一调色、焦段或运镜。每一场先写清叙事目的、观察者位置、情绪温度、空间可读性和声音关系，再选择景别、运动、光线和色彩。

## 全流程关卡

| 关卡 | 必须完成的产物 | 未通过时不得进入 |
|---|---|---|
| P0 立项 | 目标、受众、画幅、时长范围、版权、来源与改编边界 | 资产与提示词 |
| P1 叙事 | 场次、节拍、人物出场/退场、对白与旁白、未确认项 | 分镜与配音 |
| P2 资产 | 角色/场景/道具/服装/特效/声音资产矩阵与优先级 | 批量出图 |
| P3 视觉设计 | 风格 Bible、空间关系、镜头合同、关键帧计划 | 视频生成 |
| P4 受控生成 | 工作流锁定、模型锁定、输入参考、种子或可复现实验记录 | 批量队列 |
| P5 声音与剪辑 | 台词版、声音分轨、粗剪时间轴、转场意图 | 母版输出 |
| P6 验收 | 叙事、连续性、声音、技术、版权、可追溯性检查 | 成片交付 |

## 画面控制面

1. **身份**：角色脸型、年龄阶段、发型、服装、标志物和表演基调。用角色卡、多视角图和场景状态卡锁定，不以随机种子代替。
2. **空间**：景别、前中后景、人物方位、入口/出口、道具接触点、遮挡与光源。先让静帧空间成立。
3. **时间**：用可见的起始状态、动作节拍和结束状态描述变化。复杂动作按节拍拆片，而非在一个提示词里堆叠动词。
4. **镜头**：写明观众为什么此刻看这里；再写机位、景别、运动、焦段感与切点。镜头服务信息和情绪，不为了“电影感”强加摇移或炫技。
5. **风格**：以材质、光比、色温关系、空气感、颗粒/清晰度和表演尺度描述；允许不同场次有不同视觉语言，但必须在 Bible 中说明连续逻辑。

## 声音控制面

- 单独规划画内对白、画外旁白、环境底噪、拟音/效果、音乐和静默，不能用一条背景音乐代替声音设计。
- 有口型的镜头先锁定最终台词、语速、停连和声音文件；不需要口型的文字可改为画外声，避免无意义地驱动嘴部。
- 对白、音乐、音效和环境分别放到独立轨道；对白出现时为音乐留出动态空间，保留必要的呼吸、停顿和环境声。
- 每个声音条目记录来源、权利、时长、入点、出点、声像位置、混音目标和关联镜头。

## 生成与剪辑的关系

生成片段的长度由模型能力、成本和连续性决定；剪辑镜头的长度由叙事决定。可以从一个较长片段裁出短反应，也可以用多个带重叠状态的片段拼成一段完整调度。不要把任何模型的常见时长当作全片节奏规则。

先做低成本的四级测试：静帧身份与空间 → 单一动作 → 相邻镜头衔接 → 对白/声音同步。只有通过前一级，才进入下一级或批量生成。

## 镜头合同最低字段

```text
shot_id, scene_id, beat_id, edit_in, edit_out, planned_duration,
narrative_job, visible_subjects, character_refs, character_state,
scene_ref, prop_refs, spatial_layout, action_sequence, camera_plan,
lighting_color, audio_in_frame, audio_off_frame, dialogue_ids,
generation_strategy, workflow_id, model_lock, input_assets,
acceptance_criteria, review_status, output_path, notes
```

提示词只描述可观察结果。把“先后顺序、保持项、变化项、接触点、位置与遮挡”写清楚；不要同时要求互相冲突的动作、机位或情绪。
