# AI 视频与多媒体创作管理

## 项目阶段

1. **需求与版权**：明确小说/段子/改编/重构类型、时长、画幅、声音权利和交付编码。
2. **资产 Bible**：为人物、场景、道具、服装、材质、光线和风格建立参考图、文字约束、负面约束与版本号。
3. **文本拆镜**：每个镜头 3–8 秒起步，记录时间码、景别、视角、焦段感、人物位置、动作分解、道具位置、遮挡关系、背景和声音。
4. **关键帧**：先生成首帧/尾帧和必要的中间关键帧；确认人物比例、物品接触点和背景透视后再进入视频节点。
5. **受控生成**：按输入选择图生视频、首尾帧、姿态/深度/边缘控制、轨迹控制、视频局部重绘或角色替换；非人形角色优先按镜头重建，不强行套真人骨骼。
6. **镜头验收**：逐帧检查身份、肢体数量、嘴型、物品位置/细节、遮挡边缘、相机轨迹、背景、闪烁和声音对齐。
7. **后期交付**：锁定画面后再做配音、音色、口型、音效、转场和调色；保存时间轴、源素材、代理文件、参数和最终哈希。

## 镜头表最低字段

```text
shot_id, timecode, duration, aspect_ratio, camera, lens_feel,
character_refs, character_pose, action_beats, scene_ref,
prop_refs, prop_position, occlusion, lighting, positive_prompt,
negative_prompt, workflow_id, model_lock, audio_plan,
output_path, review_status, notes
```

## 一致性原则

- 人物一致性：身份锚点、三视图/多视图、服装材质和负面词；每段只改变一个主要变量。
- 背景一致性：场景板、透视/深度控制、固定机位或明确运镜；长镜头拆成短段并用重叠帧衔接。
- 道具一致性：单独道具参考图和接触点；已有原物优先做遮罩/分层恢复，不让生成模型重新发明物品。
- 遮挡一致性：人物、道具、背景分层；跨帧蒙版需要跟踪复核，手和透明物体要单独处理。
- 动作一致性：用姿态/轨迹/首尾帧约束动作，不用长篇形容词代替时间顺序。
- 嘴型与声音：先锁定台词和最终音频，再用口型/音频驱动流程；声音转换不与画面随机生成混在同一次实验中。

## 提示词骨架

```text
[主体身份与外观] + [场景/时间/光线] + [镜头/构图/视角]
+ [按时间顺序的动作和接触点] + [物品位置与遮挡]
+ [运动强度/速度/连续性] + [画面风格与材质]
+ [必须保持项] + [禁止项]
```

提示词只描述可观察结果；把“持续”“随后”“保持在画面左侧”等时序和空间关系写清楚，避免同时要求互相冲突的动作。
