# MCP、Agent 与运行前验证

## 层次

```text
Codex/Agent
  ├─ 只读审计：工作流、节点、模型、日志与版本
  ├─ 本地文件管理：母版、镜像、项目资产和 manifest
  └─ ComfyUI MCP/HTTP：排队执行、读取状态、取得输出（需明确授权）
ComfyUI Desktop Agent Panel
  ├─ 本机渲染：Use Local
  └─ 云端 Pod：Deploy new pod / Connect（另一个资源边界）
```

Agent Panel 显示“disconnected”或“couldn't list pods”通常只说明云端 Pod 控制未连接，不等于本地 ComfyUI 不能运行；先确认本地地址和 `/system_stats`/WebSocket 状态。

## 运行前检查

1. ComfyUI 版本、Python 环境和启动参数；不要在不确认解释器的情况下升级依赖。
2. 工作流 JSON 结构、节点类型和自定义节点包版本。
3. 模型文件、相对路径、精度和显存预算。
4. 输入素材存在且编码/帧率/画幅符合工作流要求。
5. 输出节点、保存目录、音频是否保留、是否可能覆盖现有结果。
6. 先用低分辨率、短帧数或单镜头做冒烟测试，再扩大规模。

## MCP 变更门禁

- 读取、列出、解析、校验默认允许；启动/停止服务、安装节点、下载模型、覆盖配置、批量排队和删除输出必须得到用户明确授权。
- MCP 返回“成功”后仍要回读文件、输出路径、工作流队列和错误日志；不能只凭 UI 绿灯认定成片通过。
- 发现节点缺失、模型缺失、显存溢出、输出为空或链接断裂时停止扩展任务，保存诊断信息并先修复最小复现。
- 对长视频使用镜头级队列和 manifest；每段输出带 shot_id、工作流版本、模型锁和生成参数，便于回滚与比较。
