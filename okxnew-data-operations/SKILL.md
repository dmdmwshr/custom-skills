# OKXnew 数据模块运维

## 范围

只处理 `C:\Users\12070\Desktop\项目开发\OKXnew`。优先使用项目常驻数据链；浏览器仅作为五个美国官方宏观发布日历、Federal Reserve 目标利率和 DOL 周度申领实际值的备用采集面，不替代 OKX K 线后台，也不成为交易授权来源。

始终保持以下边界：

- 全部 live 线性 USDT 永续只维护 K 线和必要官方合约元数据；只有当前收藏进入附加市场数据、信息面、策略、计划、授权和模拟执行。
- 只访问 OKX、BLS、BEA、Federal Reserve、Census、DOL 等计划已登记的官方公开来源；不读取 `.env`、密钥、Cookie、浏览器存储、账户、仓位或委托。
- 不抓取 CME 经济日历，不采集 OPEC 报告正文，不调用正式盘或真实下单路径。
- 自动巡检不修改源码、`PROJECT_PLAN.md`、Windows 任务或服务，不重启进程。需要工程修复时只报告证据和建议。
- 不把空响应、翻译后的页面文本或第三方镜像写成成功数据。

## 工作流

1. 读取 `http://127.0.0.1:8100/api/v1/health` 和 `/api/v1/data/monitoring`。记录服务状态、七周期 K 线应有缺口、收藏专属产品、BLS 日历/实际值、BEA/Census 日历、联储日历/目标利率、DOL 日历/周度实际值水位、持久任务死信和来源失败。
2. 若 Web/API 不可用，标记 `service_unavailable` 并停止写入；不要自行启动或重启服务。
3. 某个官方宏观产品最近成功仍在 24 小时内且状态健康时，不重复启用浏览器。仅当该日历或已登记实际值失败、陈旧，或到达每日刷新窗口时，读取并执行 [官方宏观浏览器备用采集](references/official-calendar-browser-fallback.md)。每个来源、日历与实际值子产品独立收口，一个子产品失败不得阻断其他来源。
4. 浏览器捕获必须经项目 `okxnew.data.browser_capture` 从 UTF-8 标准输入校验并导入。导入器按路由固定请求方法、官方 URL、HTTP 200、媒体类型、带时区采集时间、正文标记、大小和 SHA-256，再复用来源专用解析器和 SQLite 只追加版本存储。
5. BLS ICS 继续作为 BLS 主日历；BLS 就业发布页和年度页只登记正文哈希并与 ICS 交叉核对，不得在不一致时覆盖 ICS。BEA、联储、Census、DOL 的网页/JSON 路由可在校验后写入各自日历产品；联储政策声明和 DOL 全国周度 XML 可写入实际值产品。
6. BEA 与 Census 的公开发布网页只能作为发布证据，不能从标题、摘要或翻译后 DOM 推断完整实际值；两者结构化实际值继续等待官方 API 凭据。没有明确解析器与导入路由时不得自行扩展。
7. 导入后重新读取宏观日历、实际值与数据监控接口，按来源确认事件数、观测数、内容哈希、最远水位、最近成功和连续失败。重复正文应为幂等导入，不得新增重复版本。
8. 以自然中文报告：本次是否采集、各官方宏观源事件数/观测数/水位/哈希前 12 位、BLS HTML 与 ICS 对齐数、全市场 K 线应有缺口、收藏附加产品状态、当前失败，以及确实需要用户处理的许可、凭据或业务映射事项。

## 失败分类

- `healthy`：接口可回读且产品最近成功。
- `network_path_blocked`：某一官方固定页面或同源请求被明确拒绝；不换域名。
- `browser_unavailable`：当前 Codex 环境没有可用浏览器能力；不改用独立浏览器脚本绕过。
- `import_rejected`：路由、来源、状态、类型、哈希、时区或正文结构校验失败；不写数据库。
- `corroboration_mismatch`：BLS HTML 解析事件与当前 ICS 不一致；只保留证据哈希，不晋升、不覆盖。
- `credential_required`：BEA 或 Census 结构化实际值需要用户登记的官方 API 凭据；不以网页摘要替代。
- `service_unavailable`：OKXnew Web/API 不可访问；只报告，不擅自重启。

## 输出约束

不输出原始 ICS、完整 UUID、数据库路径、命令行或内部 JSON。只有在排障确有必要时才给出脱敏错误类别。若无需用户动作，明确写“当前无需用户处理”。
