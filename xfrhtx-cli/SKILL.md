# 消防融合通信记录

本 Skill 是调用规范，依赖独立安装的 **xfrhtx-reader 0.2.0+**。Skill 不内嵌工具源码、安装环境、数据库或附件；只维护入口定位脚本和操作指引。工具使用 JSON 接口 `schema_version=1.0`。

执行端为本机 64 位 Windows。当前工具验证了消防融合通信客户端 9.0.271.0 的特定组件；保持客户端已登录，工具自动识别其安装路径、账号及数据目录。其他系统或组件不兼容时明确说明，不自动切换主机或绕过版本核验。

## 定位工具与判断就绪

先定位本 Skill 自己的根目录，不使用旧会话中的用户名或绝对路径。用随技能附带的 `scripts/run.ps1` 调用：

```powershell
& "<本 Skill 根目录>\scripts\run.ps1" -ToolArguments @('status', '--json')
```

脚本依次读取当前用户的工具安装回执、唯一有效的命令入口和当前用户默认工具目录，不安装软件。支持 `-InstallRoot` 指定独立安装根目录或 `-EntryPoint` 指定现有 CLI。它会排除同名的融合通信图形客户端，不把启动客户端当作工具调用。

`ok=true` 且 `data.ready=true` 才表示本次可读取；历史验收不能代替当前状态。工具缺失、版本低于 0.2.0 或用户要求换机部署时，读取 [初始化与迁移](references/setup.md)。单纯查询请求不顺带安装或升级；用户已要求初始化、安装或修复同一入口时，直接完成相应操作及回读。

## 查询、导出与文件

1. 用 `sessions --json` 找到会话，`--type group` 和 `--type user` 分别限定群聊、个人聊天。名称重名时使用返回的 `session_key`；不要自行拼造人员或群标识。
2. 用 `history <session_key> --json` 读取记录；需要跨会话检索时用 `search <关键词> --json`。按请求添加时间、发送人和消息类型，避免为一个问题全量导出所有会话。完整参数和字段见 [命令与结果](references/commands.md)。
3. 默认先取小页结果；翻页保持原筛选条件，使用 `next_cursor` 直到满足所需范围。日期按北京时间，只有日期的 `--until` 包含当天。固定采集水位时显式给出截止时间，后续项目以 `message_id` 去重，不维护第二份原始数据库。
4. 用户要归档时，用 `export <session_key> --with-files -o <新目录> --json`；聊天文档、文件及清单在同一目录。读回 `manifest.json`，核对会话、范围、完成状态、缺失数量和文件关联。既有非空导出目录不会覆盖。
5. `attachments` 只列直接文件消息，`--media` 加入图片、语音和视频；`extract` 只复制本地文件。未下载附件仅在用户明确要求拉取时，用 `download <attachment_id>` 逐个处理。单个文件默认上限 200 MB；不要因列出了附件就批量下载。大小上限由工具校验。

查询、检索、导出与提取均不联网。`download` 先复用本地，确需拉取时读取该消息对应的文件服务。它不触发消息同步、不发送消息，也不改变已读状态。

## 结果解释

- 数量和时间范围只说明本机已保存记录，不代表服务器完整历史。
- 个人会话同时包含自己与对方发言。姓名没有缓存时保留发送人标识，不按语境猜测身份。
- 正常状态默认可读；其他状态仅可列占位，不展示可能已撤回或删除的旧正文，不能根据未核实状态码自行定性。
- 链接、图文卡片和引用不当成文件。媒体摘要不等于已完成识别或转写。
- 原始 `digest` 不是已证实的标准文件哈希。`verification` 说明消息与文件的关联依据；`sha256` 是实际文件内容指纹，复制后可比对。不得把路径/大小关联说成服务器哈希已验证。
- 下载失败保留不完整文件及回执，不把它们计为成功、不自动重试或删除。当前没有续传功能。

最后报告实际找到的会话、时间范围、结果数量和可用输出；有缺失或失败时单独说明。不得回传访问凭据、原始内存或整批不相关聊天内容。
