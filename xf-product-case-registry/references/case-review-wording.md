# 网上案卷检查与问题写法

## 先确认本次交办

- **日常网上巡查**由人工查卷，在底册记录并确认问题和扣分。AI用 `xf-report-filler` 按底册登记、填充原模板、核对案号和扣分合计。用人工确认的表述和扣分。碰到原卷与底册冲突，先把差异交人工确认。
- **辅助查卷或交叉评审**按用户指定的案卷、检查要点、文书清单和扣分规则核对。往期问题用来定位或参考措辞。AI自行发现的问题须有当卷证据，按当批规则报请确认或计分。常态采集的年度边界只用于采集。评审遇到跨年案卷，按项目号、单位及原卷日期定位。外市临时评审按交办目录本地交付，飞书登记须单独授权。

## 问题描述

每条写清哪份文书、哪个字段或事项、缺了什么或哪里不一致。一句话能说明就用一句。多个同类缺项可在同一条概括；具体日期和数字用来说明问题，需要时再写。用“未载明”“缺……”“……载明……，……载明……”这类直接表述。缺项用具体字段名，日期对照写出两份文书和各自日期，避免只写“填写不规范”“时间错误”。使用既有的底册及质量明细表样式和扣分栏；过程、依据、截图定位和解释留在工作记录。

| 核对情形 | 句式示例 |
| --- | --- |
| 电子文书文字缺项 | 《责令限期改正通知书》未载明产品规格型号、标称生产企业和检验报告编号。 |
| 两份文书的同一日期记载不同 | 《责令限期改正通知书》载明检查日期为3月5日，初查记录载明3月2日。 |
| 纸质版划除或画叉 | 《不合格消防产品情况通报函》标题未划除不适用的“生产／销售”选项。 |
| 缺纸质版的说明 | 《责令限期改正通知书》未上传纸质版。 |
| 汇总记录初查、复查事实 | 1月8日初查，基数10、检查2，结果不合格。3月12日复查，基数10、检查2，结果合格。 |

以上为写作示例。具体事实、适用扣分和模板字段以本案及当批材料为准。

## 常见误判

- **电子文字和纸质样式**。电子版中可核实的缺项、日期冲突等文字记载问题，可按当批规则计分。纸质签章、手写划除生产／销售、以“×”划销空项等样式，依据上传的纸质原件扫描或照片。卷内仅见电子件时，相关文书注明“未上传纸质版”，该电子件仍可核对文字。
- **检验报告日期**。按同一产品、同一轮次的报告原件签发栏记录。登记日期、检验日期、结果通知书日期和送达日各记其本身。找不到报告正文或签发栏、签发栏模糊时，在工作记录写明编号、找到的材料及未取得的页面，必要时给原页截图供人工辨读。
- **复检和复查**。复检申请、受理凭证只能证实复检已申请或受理；用同一抽样批次的复检报告或结果通知书确认复检结论和相应日期。整改复查看复查记录中的日期、基数、实际检查数量及结果。在适用的江苏监督执法工作规范下，复检合格即结束本次监督检查，无需另做整改复查。初查和复查的基数、检查数按文书记载写事实。卷内未载更换数量不作为问题或扣分项。
- **检查要点**。详情界面可见“双随机、一公开”时，相应要点按已显示记录。按当批范围检查监督视频、认证机构等项目。需要核对企业信用时，按卷内全称核对，查无结果据实写查询口径，企业注销以登记状态的可靠证据确认。

## 成果与证据

- 提交用的质量明细表、底册和汇总只写已确认的问题和必要事实。待核问题与原页截图留在过程文件。用户指定“标绿有效、标黄剔除”时，绿项按确认结果计分，黄项从提交稿剔除。日常月度公开材料沿用底册括号前原文，标黄不公开也不计分。年度内部汇总沿用其既有的括号、备注及黄色标记规则。
- 用户要求截图时，保留能识别案卷和文书的关键页。涉及两文书冲突时保存两处事实，格式问题用纸质原页，电子文字问题用同份电子文书原页。原案卷压缩包保留，解压副本按案卷归放，可用“序号 文书名（纸质扫描／系统电子件，文号）”命名。
- 交付前逐案对照底册、质量明细表和汇总的有效问题与扣分，核对截图可定位、既有表式可正常打开，清理正式稿中的过程备注。
