# 来源年度总水位

年度目标是监督系统“本年”完整案卷任务清单与本地项目编号总账逐项对应。自建系统优先登记经文书确认的不合格子集，不要求其登记数立即等于年度来源数。

## 范围与证据

1. 进入产品监督的任务查询，分别读取日常监督、开业前检查、消防装备抽查、社会单位产品抽查、举报投诉核查、火灾事故调查核查六个入口。清空其他条件，选择“本年”和“全部管辖单位(含派出所)”，执法单位、状态、检查结果及任务来源不限定。实际日期字段由页面回读，2026-09-20 的已验证标签为“创建时间”。来源年度和按初查日期计算的统计年份分开保存。
2. 同一轮使用一个 baselineId，各类别使用自己的正式批次。每类完整列表连续两轮稳定，保留实际筛选、列表及截图证据。页面总数、文书数、来源标识数、去重项目数分别计数。点击菜单后必须核对实际路由中的类别与活动菜单；仅菜单高亮不能证明跳转成功。
3. 入口提示“开发测试中，暂时不能使用”时保存不可用证据、保留覆盖未核实；不能记零、重复读取旧页或直接进入未开放路由。2026-09-20 消防装备入口实际出现该提示，其余五类已读取；这是当日观测，后续以实时页面为准。
4. 已保存的年度文书清单只用于历史绑定与候选优先级，不能替代年度任务清单。错误类别的捕获证据保留供审计，但从年度计数及成员集合排除。较新的未完成基线不能被旧成功基线掩盖。

## 最小身份索引

先复用已由详情证明的 RWID 与项目编号绑定。同一项目的多个 RWID、清单和批次合并到同一记录。列表没有项目编号时保留待关联，禁止编造或用 RWID 当项目编号。

scripts/annual_browser.py 使用既有官方浏览器命名会话。--configure 设置本年查询；默认只采列表，--max-pages 限制本次页数；--identities --limit 限制本次最小详情读取。--browser-cwd 必须为创建该命名会话的目录。脚本不读取凭据或浏览器存储，不下载正文，不上传，不触发识别；登录先按当前授权的独立入口处理。

身份读取按当前 RWID 找到真实表格行，虚拟表格须滚动到对应业务行，不能按旧行号盲点。进入详情后连续两次读取项目编号与单位，并校验详情 URL 中的 RWID，保存本案截图和最小证据。仅当前项目文书目录参与候选提示，不把关联的其他项目目录混入本案。已绑定身份重跑直接复用，正在上传、已归档的断点与系统绑定保持不变。

年度索引确认之前，不要求合格案收齐正文；分类未知的不能标为合格。整改通知优先于普通检查记录进入核实队列；通知存在仅为候选，必须依据初查产品的有效结果确认，抽样复检采用最终结果。目录显示已结案合格也不能自动推定全部初查产品合格。

## 查询与恢复

- source coverage --year YYYY 默认输出年度覆盖摘要，--details 才展开全部身份。
- ledger status --scope source-year --year YYYY 查看本年度来源成员；--scope all 是全部已知案，--scope batch 保留指定批次。各范围仍共用四个分类视图及五项独立进度。
- source scan-plan 默认 auto：基线未完整对齐时返回 annual-baseline；完成后返回 recent。显式 recent 也会显示未完成的年度前提，不能静默越过。指定旧批次可继续原断点，保持原筛选。
- ledger index-history 默认报告差异，--apply 合并已验证身份和文书集合；不下载、识别或上传。来源观察日期来自来源证据，本地索引处理不能刷新来源时刻。

分页跳转后同时检查提交页码和行号范围、RWID 集合。2026-09-20 发现页码输入框会改变显示但不加载新列表，因此当前实现使用真实页码按钮及前后页按钮。页面显示空白归一化只用于单位名称比对，保存的业务身份仍按真实 RWID 和项目编号。

基线只有六类查询证据有效、列表稳定、身份缺口与冲突清零、每案存在总账记录才能标为完成。可用部分仍可优先处理已确认不合格案；缺失入口不得阻碍独立可安全完成的工作，也不能用局部成功冒称全年对齐。
